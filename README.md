## 模型提供商

设置面板现已内置以下预设：

- OpenAI Compatible
- Kimi
- DeepSeek
- 豆包

选择预设时会自动填充推荐的 API Base URL、接口模式和默认模型；同时仍然保留手动填写 provider、model、apiBaseUrl 的能力，便于接入代理服务、私有网关或其他 OpenAI 兼容供应商。

常见示例：

- Kimi: https://api.moonshot.cn/v1
- DeepSeek: https://api.deepseek.com/v1
- 豆包: 通常填写火山方舟提供的 OpenAI 兼容地址，并使用你自己的 endpoint 或模型 ID
